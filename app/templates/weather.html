How to read this

  • Current: Open-Meteo's latest model analysis for the point. Observation time is the provider's timestamp; retrieval time is when this server asked.
  • Recent / forecast rainfall: hourly model values, labelled separately. Forecast is never shown as observed.
  • Not reported: the provider returned nothing for that field. It is never shown as 0.
  • Model coverage is separate from weather availability.
